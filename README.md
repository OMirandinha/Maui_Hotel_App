# Hotel App

Sistema de reserva de hospedagem desenvolvido com .NET MAUI para cálculo de diárias e gestão de reservas.

## Sobre o Projeto

O Hotel App é um aplicativo multiplataforma que permite aos usuários calcular o valor de estadia em um hotel, considerando:
- Tipo de suíte
- Número de hóspedes (adultos e crianças)
- Período de estadia (check-in e check-out)
- Taxas adicionais (serviço, limpeza, por hóspede)

- ## Funcionalidades

- [x] Seleção de tipo de suíte (Standard, Dupla, Deluxe, Presidencial)
- [x] Definição de número de adultos e crianças
- [x] Seleção de datas de check-in e check-out
- [x] Cálculo automático do valor total
- [x] Detalhamento de taxas (serviço, limpeza, por hóspede)
- [x] Validação de datas (check-out > check-in)
- [x] Tela "Sobre" com informações do aplicativo
- [x] Interface intuitiva e responsiva

## Tecnologias Utilizadas

- .NET 8.0
- .NET MAUI (Multi-platform App UI)
- C# 12.0
- XAML
